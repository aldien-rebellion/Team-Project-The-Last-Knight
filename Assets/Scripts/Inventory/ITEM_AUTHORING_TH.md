# คู่มือเพิ่มไอเทมและเชื่อมรูป

## โฟลเดอร์ที่ใช้

- รูปไอเทมใหม่: `Assets/Resources/CharacterStatus/Items/`
  - `Consumables/` ยา อาหาร ของใช้
  - `Equipment/` อาวุธ เกราะ รองเท้า เครื่องประดับ
  - `Materials/` วัตถุดิบและของเควสต์
- ข้อมูลไอเทม: `Assets/Resources/Items/Definitions/` แบ่งโฟลเดอร์ย่อยได้
- Prefab ของที่เก็บในฉาก: `Assets/Prefabs/Items/WorldItemPickup.prefab`

รูปเดิมยังอยู่ตำแหน่งเดิมเพื่อรักษาลิงก์ ไม่ต้องคัดลอกรูปใหม่ไปไว้ที่ `Assets/sprites/UI/CharacterStatus/Items/` ซ้ำอีกแห่ง

## เพิ่มไอเทมใหม่

1. ลาก PNG พื้นหลังโปร่งใสเข้าโฟลเดอร์รูปตามหมวดด้านบน
2. เลือกรูปใน Project ตั้ง Texture Type เป็น **Sprite (2D and UI)** และ Sprite Mode เป็น **Single** แล้วกด **Apply** หากเป็น sprite sheet ให้ใช้ Multiple และ Slice ก่อน แล้วเลือก Sprite ย่อย
3. เปิดเมนู **The Last Knight > Items > Create New Item** จะสร้างไฟล์ข้อมูลในโฟลเดอร์ที่ระบบโหลดอัตโนมัติ
4. เปลี่ยนชื่อไฟล์ตามไอเทม กรอก **Id** เช่น `potion_small` (ไม่ซ้ำ ห้ามมีช่องว่างหน้า/หลัง) และ **Display Name** เป็นชื่อที่ผู้เล่นเห็น
5. ลากรูปจาก Project ใส่ช่อง **Icon** ใน Inspector ของไฟล์ไอเทม ไม่ต้องพิมพ์ path และชื่อไฟล์รูปไม่จำเป็นต้องตรงกับ Id
6. กรอก Type Name, Description, Category, Max Stack (อุปกรณ์แนะนำ 1)
7. ถ้าเป็นของใช้ ให้เปิด Is Consumable เลือก Use Effect และ Effect Amount เช่น Heal + 25 คือฟื้นเลือด 25 หน่วย
8. เปิด **The Last Knight > Items > Validate Items** ดู Console และคลิกข้อความเพื่อหาไฟล์ที่ต้องแก้
9. หยุดแล้วเริ่ม Play ใหม่เพื่อทดสอบ ข้อมูลที่สร้างไว้ในกระเป๋าระหว่าง Play ไม่อัปเดตย้อนหลังเมื่อแก้ไฟล์

## แก้ไอเทมเดิม

เลือกไฟล์ใน `Assets/Resources/Items/Definitions/` แล้วแก้ชื่อ คำอธิบาย รูป หรือขนาดกองได้ทันที ค่า **Legacy** เก็บพฤติกรรมเดิมจากโค้ดไว้ หากต้องการเปลี่ยนจำนวนเลือดที่ฟื้น ให้เลือก Heal และกรอก Effect Amount

เมนู **Create Missing Legacy Definitions** สร้างข้อมูลของไอเทมเดิมที่ยังไม่มีไฟล์ โดยไม่ทับไฟล์ที่มีแล้ว ระบบใช้ข้อมูลจากไฟล์ก่อน และใช้โค้ดเดิมสำรองหากยังไม่มีไฟล์

อย่าเปลี่ยน Id ของไอเทมเดิมที่มีในเซฟแล้ว เช่น `potion_heal` เพราะเซฟอ้างอิง Id; เปลี่ยน Display Name หรือชื่อไฟล์ได้ การย้ายรูปให้ทำใน Unity เพื่อรักษาไฟล์ .meta และการเชื่อมโยง

## ทำให้ไอเทมปรากฏในเกม

สร้างไฟล์ข้อมูลอย่างเดียวจะยังไม่แจกไอเทมให้ผู้เล่น:

- ลาก `WorldItemPickup.prefab` ลงฉาก แล้วตั้ง **Item Data > Id** ให้ตรงกับ Id ในไฟล์ข้อมูล และ **Count** เป็นจำนวนที่ต้องการ เมื่อเริ่ม Play ระบบจะอ่านรูปและรายละเอียดจากข้อมูลกลาง ช่องอื่นใน Item Data จะถูกแทนที่จากข้อมูลกลาง
- ในโค้ดใช้ `ItemRegistry.CreateItem("potion_small", 3)` แล้วส่งให้ `InventoryManager.Instance.AddItem(...)` หรือ `WorldItemPickup.Spawn(...)` ตามระบบแจกของ/ดรอปเดิม
- เซฟเก็บ Id และจำนวน เมื่อโหลดจะเชื่อมรูปและผลการใช้จากไฟล์ข้อมูลอีกครั้ง

## ผลการใช้ที่รองรับ

None = ไม่มีผลใช้, Legacy = พฤติกรรมเดิมตาม Id, Heal = ฟื้น HP, RestoreStamina = ฟื้น Stamina, AddGold = เพิ่มเงิน, AddStatPoints = เพิ่มแต้ม, MightBuff = บัฟโจมตีเดิม 25% นาน 30 วินาที (ไม่ใช้ Effect Amount)

ยา Heal/Stamina ใหม่จะไม่ถูกใช้ทิ้งเมื่อค่านั้นเต็ม อาวุธ/เกราะที่เพิ่มข้อมูลยังไม่ได้สร้างระบบค่าสวมใส่ใหม่ให้เอง ระเบิดควันและลูกดอกเดิมยังไม่มีผลใช้งานในโค้ด จึงจะแสดงคำเตือนเมื่อ Validate จนกว่าจะพัฒนาพฤติกรรมดังกล่าว

รูนทั้งสี่เป็นไอเทมเควสต์แยกชนิด ซ้อนกองไม่ได้ รับจากจุดที่กำหนดแล้วจะเห็นเป็นของดรอปให้เดินไปเก็บ ที่ประตูปราสาทเลือกแต่ละรูนเพื่อใส่เสาและใช้รูนนั้นหนึ่งชิ้น
